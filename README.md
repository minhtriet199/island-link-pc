# island-link-pc

PC side of **Island Link**: a small Go helper that links the Island shell (Hyprland, CachyOS) to the phone app
[island-link-android](https://github.com/minhtriet199/island-link-android).

- Shows the pairing QR code, keeps one encrypted connection to the paired phone
- Phone notifications → normal desktop notifications (Island bubbles)
- Sends Download mode progress to the phone and runs the actions picked there

Light in the background; Island is the UI. Same Wi-Fi only for now.

Status: just started.
